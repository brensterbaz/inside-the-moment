## Full participant brief

The [Innovation Studio getting-started brief](https://innovationstudio.microsoft.com/hackathons/insidethegamedeveloperhackathon/home/getting_started) and its [full challenge](https://innovationstudio.microsoft.com/hackathons/insidethegamedeveloperhackathon/executive_challenge_details/5078/about) were read in the user's signed-in Chrome session on 15 October 2026. The complete structured import is in [official brief notes](source/OFFICIAL_BRIEF.md).

The challenge describes an Azure-based insights engine with five stages: ingest, interpret, explain, render and personalise. It also calls for narratives/recaps and multilingual storytelling. Suggested player, pass, speed and video-analysis features should not all be treated as mandatory scope. Each project must link to a challenge; no portal project or link was created during this import.

The five judging areas each carry 20%: technical implementation, agentic innovation, real-world impact, user experience/presentation and category adherence. See the [project mapping](PROJECT_BRIEF.md#challenge-fit-and-evidence) for the planned demonstration.

## Public rules summary

| Milestone | Europe/London |
| --- | --- |
| Registration closes | 20 October 2026, 20:00 BST |
| Submission closes | 28 October 2026, 06:59 GMT |

The official submission deadline is 27 October, 23:59 Pacific. Time conversions use `America/Los_Angeles` and `Europe/London`.

Submission needs:

- A newly created, functioning AI project using synthetic football-realistic data.
- Event ingestion, interpretation, explanation, presentation and personalisation.
- A public GitHub repository, project pitch and accessible working demo/test build.
- A publicly linked video under two minutes showing the intended device/platform.
- Rights to included materials and English submission materials or translations.

Organisers do not supply match footage/data. Judges may request specialised hardware access. Entrants retain ownership but grant broad usage rights on submission; review the full terms before entering.
